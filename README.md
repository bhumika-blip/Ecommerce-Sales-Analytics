# Ecommerce Sales Analytics Dashboard

## Project Overview
This mini project focuses on analyzing ecommerce sales data using Microsoft Power BI. It presents important business information through interactive visualizations and KPI cards.

## Objectives
- Analyze total sales and profit.
- Understand sales performance across product categories.
- Compare sales across different regions and cities.
- Identify monthly sales trends.
- Present insights through an interactive dashboard.

## Tools and Technologies
- Microsoft Excel
- Microsoft Power BI
- Power Query
- Data Visualization

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Profit by Category
- Sales by City
- Interactive slicers for Region, Category and Month

## Project Files
- Excel dataset
- Power BI dashboard (.pbix)

- Project report (DOCX and PDF)
